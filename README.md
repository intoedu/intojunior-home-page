# 인투주니어학원 홈페이지 (본사)

> 읽고, 말하고, 성적과 경험까지 완성하는 영어 교육

초등·중등 영어 전문 **인투주니어학원**의 공식 홈페이지(본사)입니다.
특정 지점이 아니라 브랜드 전체를 소개하고, 운영 중인 **캠퍼스는 목록으로 안내**합니다.
한국어 / English 2개 언어를 지원하며, 정적 사이트로 만들어져 어떤 호스팅에도 그대로 올릴 수 있습니다.

## 📌 먼저 보내주셔야 할 자료

아래 자료를 주시면 바로 반영해 사이트를 완성합니다.
지금은 **"사진 준비 중"** 같은 임시 화면이 자연스럽게 표시되고 있어, 자료 없이도 사이트를 보고 검토하실 수 있습니다.

### 1. 이미지 · 영상 (가장 급한 것)

| 자료 | 쓰이는 곳 | 권장 규격 | 비고 |
| --- | --- | --- | --- |
| **로고 원본** | 헤더 · 푸터 · 파비콘 | AI / SVG / PNG(투명배경) | 현재는 임시 로고를 사용 중입니다 |
| **대표 사진 1장** | 메인 상단 | 세로형 (예: 1200×1500) | 수업 장면 또는 강의실 |
| **원장님 사진** | 소개 페이지 | 세로형 (예: 1000×1250) | 인사말 옆 |
| **학원 사진 6장** | 갤러리 | 가로형 (예: 1600×1000) | 강의실 / 리딩존 / 스피킹 수업 / 자습·클리닉 / 상담실 / 발표회 |
| **소개 영상** | 메인 영상 섹션 | 유튜브 링크 | 유튜브에 올리신 뒤 주소만 주시면 됩니다 |
| 기존 인쇄물 | 문구 참고 | PDF / 사진 | 있으시면 문구를 다듬는 데 활용합니다 |

### 2. 사진 (올리기만 하면 자동 반영됩니다)

`public/photos/` 폴더에 아래 이름으로 올리면 **코드를 고치지 않아도** 사이트에 나타납니다.
확장자는 jpg · png · webp 아무거나 괜찮습니다.

| 파일 이름 | 쓰이는 곳 | 권장 크기 |
| --- | --- | --- |
| `director` | 소개 페이지 · 대표 인사말 | 세로형 1000×1250 |
| `hero` | 메인 첫 화면 | 세로형 1200×1500 |
| `daejeon-doan` | 캠퍼스 안내 | 가로형 1600×1000 |
| `room1` ~ `room6` | 메인 갤러리 6칸 | 가로형 1600×1000 |

올리는 곳 → **저장소 → `public/photos` → Add file → Upload files**

> 채팅에 붙여넣은 이미지는 파일로 저장되지 않습니다. ZIP 첨부나 위 방법을 이용해 주세요.

### 3. 아직 비어 있는 문구 (알려주시면 채웁니다)

근거 자료 없이 임의로 쓴 문구는 모두 비워두었습니다. 아래를 알려주시면 채워 넣겠습니다.

- [ ] **대표 인사말** — `src/content/ko.ts` 의 `about.greeting.paragraphs`
- [ ] **교육 철학** — 강조하고 싶은 원칙 3~4가지 (`about.philosophy.items`)
- [ ] **"이런 학생에게 추천합니다"** 목록 (`about.fitFor.items`)
- [ ] **강사진 소개** (`about.teachers`)
- [ ] **시설 소개 문구** (`about.facility.description`)
- [ ] FAQ 중 답변이 빈 항목 — 차량 운행 / 주차 / 학부모 상담 / 결석 보강
      (답변이 빈 질문은 화면에 나오지 않습니다)

### 4. 도메인

- 원하시는 주소: `www.intojunior.com`
- **도메인은 학원에서 직접 구입·결제**하시고, 구입 후 알려주시면 사이트에 연결해 드립니다.
- 도메인 구입처는 어디든 상관없습니다 (가비아 · 후이즈 · Cloudflare 등, 보통 연 1~2만원대).
- 구입하신 뒤 `src/config/site.ts` 의 `url` 값을 실제 주소로 바꿔주시면 됩니다.

## 💌 문의는 이렇게 받습니다

이 홈페이지에는 **입력 양식(문의 폼·신청서)이 없습니다.**
양식을 두려면 접수받을 서버나 외부 유료 서비스가 필요한데, 그런 것 없이도
학원 문의는 전화가 가장 빠르고 확실하기 때문입니다.

대신 사이트 곳곳에서 바로 연결되도록 배치했습니다.

- **전화** — 헤더 버튼, 모바일 하단 고정 버튼, 각 페이지 하단 CTA에서 한 번에 통화 연결
- **이메일** — 문의하기·푸터에서 메일 앱 바로 열기
- **방문** — 주소를 누르면 네이버지도 / 카카오맵 / 구글지도로 이동
- **카카오톡 채널** — `src/config/site.ts` 에 주소를 넣으면 문의하기 페이지에 자동으로 나타납니다

`문의하기` 페이지에는 연락 방법과 함께 **상담 진행 4단계**(전화 → 레벨테스트 → 결과 상담 → 반 배정)를
안내해 두어, 학부모님이 무엇을 기대하면 되는지 바로 알 수 있게 했습니다.

> 나중에 온라인 신청서가 꼭 필요해지면 그때 추가할 수 있습니다.
> 다만 접수 방법(이메일 자동 전송 등)을 정해야 하므로 미리 말씀해 주세요.

## 🛠 개발 · 빌드

```bash
npm install       # 최초 1회
npm run dev       # 개발 서버 → http://localhost:3000
npm run build     # 정적 사이트 생성 → out/ 폴더
npm run lint      # 코드 점검
```

`npm run build` 를 실행하면 `out/` 폴더에 **완성된 HTML · CSS · 이미지 파일**이 만들어집니다.
데이터베이스도, 서버도, 로그인도 필요 없습니다. 이 폴더를 웹서버에 올리기만 하면 끝입니다.

> **특정 업체에 묶여 있지 않습니다.**
> Vercel · Supabase 같은 유료 서비스를 전혀 쓰지 않습니다. 코드에도, 설치된 패키지에도 없습니다.
> (Next.js 는 Vercel 이 만든 오픈소스 도구이지만, 만들어진 결과물은 평범한 웹 파일이라
> Vercel 없이도 완전히 동작합니다. 나중에 다른 곳으로 옮겨도 파일만 복사하면 됩니다.)

### 어디에 올릴 수 있나요

| 방법 | 비용 | 이런 경우에 |
| --- | --- | --- |
| **GitHub Pages** | 무료 | **이미 설정 완료.** `main` 에 올리면 자동으로 배포됩니다 |
| **기존 웹호스팅** (카페24 · 가비아 · 닷홈 등) | 월 1천~5천원대 | 이미 쓰던 호스팅이 있을 때. `out/` 폴더 안의 파일을 FTP 로 올리면 끝 |
| **Cloudflare Pages** | 무료 | GitHub 저장소를 연결하면 자동 배포. 국내 속도가 빠릅니다 |
| **Netlify** | 무료 | Cloudflare 와 비슷 |

무료 서비스들도 **개인 도메인 연결과 https(보안 인증서)를 무료로 제공**합니다.
도메인만 직접 구입하시면 그 외 유지비는 들지 않습니다.

#### FTP 로 올리는 경우

```bash
npm run build       # out/ 폴더 생성
```

`out/` 폴더 **안의 내용물**을 호스팅의 웹 루트(보통 `public_html` 또는 `www`)에 그대로 올립니다.
폴더째가 아니라 안의 파일들을 올려야 합니다.

#### GitHub Pages (설정 완료)

`.github/workflows/deploy.yml` 이 들어 있어서, **`main` 브랜치에 코드가 올라가면
자동으로 사이트를 새로 만들어 배포**합니다. 따로 해주실 일은 없습니다.

처음 한 번만 저장소 설정을 확인해 주세요.

> **Settings → Pages → Build and deployment → Source** 를 **`GitHub Actions`** 로 지정
>
> (`Deploy from a branch` 로 되어 있으면 소스 코드가 그대로 노출되고
> README 만 덩그러니 보입니다. 위 워크플로가 자동으로 바꿔주기도 하지만,
> 안 되면 직접 바꿔주세요.)

배포 상태는 저장소 **Actions** 탭에서 볼 수 있습니다. 보통 2~3분 걸립니다.

**주소는 자동으로 맞춰집니다.**
지금은 `intoedu.github.io/intojunior-home-page/` 처럼 하위 경로에 올라가지만,
나중에 Settings → Pages → Custom domain 에 `www.intojunior.com` 을 넣으면
경로·링크·이미지 주소가 **코드 수정 없이** 알아서 바뀝니다.

> 미리보기 주소(github.io)로 배포될 때는 검색엔진이 수집하지 않도록 자동 차단됩니다.
> 실제 도메인을 연결하면 자동으로 해제됩니다.

#### Cloudflare Pages 로 올리는 경우

1. [pages.cloudflare.com](https://pages.cloudflare.com) 에서 이 GitHub 저장소를 연결합니다.
2. 빌드 명령어 `npm run build`, 출력 폴더 `out` 으로 설정합니다.
3. Custom domains 에서 `www.intojunior.com` 을 추가하고, 도메인 구입처에서 안내된 값을 등록합니다.

### 외부 서비스 사용 현황

완성된 사이트가 실제로 불러오는 외부 주소는 아래가 전부입니다.

| 외부 요청 | 언제 | 비고 |
| --- | --- | --- |
| 구글 지도 | 오시는 길·메인 지도 | API 키·계정 불필요 |
| 유튜브 | 방문자가 재생 버튼을 눌렀을 때만 | 누르기 전에는 아예 불러오지 않습니다 |
| 네이버지도 · 카카오맵 | 방문자가 버튼을 눌러 이동할 때 | 단순 링크 |

글꼴(Pretendard)은 사이트 안에 함께 넣어두어 **외부 CDN에 의존하지 않습니다.**
분석 도구·광고·추적 스크립트는 하나도 넣지 않았고, **데이터베이스나 로그인, 입력 양식도 없습니다.**
방문자의 개인정보를 수집하는 기능 자체가 없습니다.

> Next.js 는 빌드할 때 익명 사용 통계를 보냅니다(사이트 방문자와는 무관, 개발자 PC 에서만).
> 원하지 않으시면 한 번만 실행해 두면 됩니다: `npx next telemetry disable`

## ⚙️ 기술 구성

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4** — 디자인 토큰은 `src/app/globals.css` 의 `@theme` 에 정리되어 있습니다
- **정적 내보내기**(`output: "export"`) — 서버 없이 동작
- **Pretendard 자체 호스팅** — 외부 CDN에 의존하지 않아 빠르고 안정적입니다
  (브라우저가 화면에 실제로 쓰인 글자 조각만 내려받습니다)
- **지도** — API 키 없이 동작하는 구글 지도 임베드 + 네이버지도 / 카카오맵 바로가기
- **영상** — 클릭하기 전에는 유튜브를 불러오지 않아 페이지가 가볍습니다

### 검색 최적화 (SEO)

- 페이지별 제목·설명, `canonical`, 한/영 `hreflang` 자동 생성
- 카카오톡·검색 공유용 OG 이미지 (`public/og.png`)
- `sitemap.xml`, `robots.txt` 자동 생성
- 학원 정보 구조화 데이터(JSON-LD) — 검색 결과에 주소·전화·운영시간이 노출될 수 있습니다
- FAQ 구조화 데이터 — 검색 결과에 질문/답변이 함께 노출될 수 있습니다

### 접근성 · 사용성

- 키보드만으로 모든 기능 사용 가능, 포커스 표시 제공
- 모션 최소화 설정을 켠 사용자에게는 애니메이션이 적용되지 않습니다
- 자바스크립트가 꺼져 있어도 모든 내용이 보입니다
- 모바일 하단에 전화·예약 버튼이 항상 떠 있습니다
